# lexia-media

Kit e arquivo dos posts do Instagram da Lexia AI (@uselexia.ai).

- `brand/BRAND.md`: guia de marca e regras de conteúdo.
- `ROUTINE.md`: passo a passo da rotina diária (2 posts: 08:00 e 18:00).
- `brand/assets/`: logos.
- `templates/`: artes de referência em HTML.
- `tools/render.py`: exporta HTML para JPG 1080×1350.
- `posts/`: artes publicadas, por data, e `LOG.md` com o histórico.

As imagens ficam neste repositório público porque o Metricool precisa de um link público para buscar cada arte.
